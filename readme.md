## Recent Personal Projects

### Roulette Together  
Add options to a spinning wheel and let chance decide.

#### Modes:
- **Spin Alone** – Add items and spin the wheel by yourself.  
- **Spin Together** – Create or join a lobby with friends where everyone can suggest and veto items before spinning.  
- **Prize Picker** – Randomly select winners and assign prizes—perfect for raffles and giveaways.

**Tech Stack:** React, Firebase Realtime DB  
[Check it out](https://roulettetogether.com/)
